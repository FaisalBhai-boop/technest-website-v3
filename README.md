# TECHNEST Website

## Live karne ke steps:
1. Is folder ko GitHub par ek naye repository mein upload karein.
2. Vercel.com par jaein -> "Add New Project" -> GitHub repo select karein.
3. "Deploy" button dabayein. Bas!

Vercel khud detect kar lega ke ye Vite project hai — kuch aur set karne ki zaroorat nahi.
